# KOREA: UNFILTERED

An editorial website exploring South Korean history, culture, food, music, and contemporary life.

**Live website:** https://koreaunfiltered.netlify.app/

## Overview

A responsive, single-page visual editorial concept with a mobile navigation menu, an interactive historical timeline, and selectable music genres.

## Technologies

- HTML5
- CSS3 (responsive layouts and typography)
- Vanilla JavaScript (navigation and interactive content)
- Netlify (deployment)

## Running locally

Download the repository and open `index.html` in a browser. No build step is required.

## Image policy

This public source-code edition intentionally replaces third-party photographs with original SVG placeholders in `assets/`. The deployed showcase may display separately sourced photographs. **The photographs are not licensed or redistributed through this repository.** Replace placeholders only with images you have permission to publish.

## Development note

This project was developed with AI assistance. Design direction, content selection, review and iteration were guided by the project owner. The source is shared for transparency and further learning.

## Portfolio focus

Responsive visual design, content hierarchy, semantic HTML, CSS layout, and vanilla JavaScript interaction.
